# Bronkhorst EL-FLOW Prestige: автоматическое подключение и программа эксперимента

`bronkhorst_gui.py` показывает все подключённые USB-COM интерфейсы, а затем подключает EL-FLOW Prestige по выбранному оператором COM-порту через штатный Bronkhorst FLOW-BUS/ProPar протокол. Прибор идентифицируется серийным номером, моделью и текущим потоком, поэтому переназначение Windows с `COM3` на `COM7` не требует ручной правки программы.

Поиск выполняется только командами **чтения** ProPar. Запись уставок возможна после включения управления. Старт автоматического плана требует подтверждения; ручные кнопки установки и обнуления отправляют команды сразу.

Окно разделено на вкладки **Подключение**, **Параметры / калибровка**, **Эксперимент** и **Консоль**. Консоль содержит журнал подключений, команд, этапов эксперимента и ошибок с временем события; сохраняются последние 2000 строк в памяти. При повторяющейся ошибке связи внутренний сеанс ProPar пересоздаётся.

> Это не система противоаварийной защиты. Для H₂ обязательны независимые отсечные клапаны, защита давления, проверка герметичности, безопасный сброс и аварийное отключение. Закрытие GUI, USB и Modbus не являются надёжным способом остановить опасный поток.

## Запуск

В терминале VS Code:

```powershell
.\.venv\bin\python.exe bronkhorst_gui.py --config config.json
```

Если окружение ещё не создавалось:

```powershell
python -m venv .venv
.\.venv\bin\python.exe -m pip install -r requirements.txt
```

В VS Code выберите `.venv\bin\python.exe` через `Python: Select Interpreter`.

## Первый запуск с приборами

1. Отключите подачу газа и подключите USB–RS485/RS232 адаптеры и MFC.
2. В `config.json` задайте скорость, чётность и стоп-биты, совпадающие с MFC. Программа не может безопасно подбирать их автоматически.
3. Укажите скорость с заводской наклейки прибора (`38400` — типичное значение для RS232 ProPar). Стандартное прямое RS232-подключение использует локальный адрес ProPar автоматически.
4. На вкладке **Подключение** выберите `COM5` в списке и нажмите `Connect selected`, затем так же подключите второй MFC, например `COM6`. Подключённые устройства появятся в таблице с серийным номером, текущим COM-портом, диапазоном и измеренным расходом.
5. Один раз для каждого серийного номера выберите роль `H2` или `Alkene` и нажмите `Save gas role`. Роль сохраняется в `config.json`, поэтому после переподключения USB определяется снова по серийному номеру, а не по COM-порту.
6. Для каждого MFC выберите `Read flow` или `Set flow` и нажмите `Save MFC mode`. В режиме чтения программа показывает расход и уставку, но блокирует отправку новой уставки. В режиме выставления доступны ручные команды; автоматический план запускается, только если оба канала H₂ и алкена выбраны в этом режиме.

На четвёртой вкладке **Консоль** журнал фиксирует время нажатия кнопки, открытие COM, паспортный ответ ProPar, повторное создание сеанса, команды уставок и ошибки доступа. Обновление списка COM не открывает последовательные порты и не мешает FlowSuite или стороннему монитору.

Автоматическое определение подтверждает, что устройство отвечает как Bronkhorst по используемым регистрам. Оно не способно физически узнать, какой баллон подключён к конкретной линии: роль H₂/алкен должен назначить оператор.

## Газовый набор и условия для каждого MFC

EL-FLOW Prestige содержит официальную встроенную Bronkhorst-базу газов; это не таблица, рассчитанная приложением. GUI читает у каждого серийного номера активный `fluid set`: его номер, название газа, заданные входное и выходное давление, температуру и опорное давление объёмной единицы.

Для смены газа выберите **Fluid-set slot** (0–7), введите ожидаемое имя газа и нажмите `Activate selected fluid set`. Это переключает только уже преднастроенный в приборе набор; затем программа читает фактическое имя газа обратно из MFC. Если оно не совпадает с сохранённым ожидаемым именем, появляется `GAS PROFILE MISMATCH` и поток начинать нельзя.

Кнопка `Save active fluid-set conditions` сохраняет и передаёт в активный набор условия `inlet`, `outlet`, `temperature` и `reference`. Давления вводятся в **bar(a)**, то есть для показаний манометра в bar(g) необходимо прибавить атмосферное давление. Эти поля являются условиями модели газа и перевода массового расхода в объёмный, а не заменой датчика реального давления или заводской метрологической калибровки.

Профили, подтверждённые оператором, сохраняются в `config.json` отдельно для каждого серийного номера и слота. Не меняйте заводские коэффициенты датчика, диапазон или параметры клапана из этого приложения. Газовая база и переключение fluid set описаны Bronkhorst в [списке встроенных газов](https://www.bronkhorst.com/en-us/service-support/faq-en/installation/which-gases-are-embedded-in-the-el-flow-prestige-mass-flow-meter-controller/?pdf=true) и [руководстве EL-FLOW Prestige](https://products.bronkhorst.com/media/dtrhzjhu/917084-manual-el-flow-prestige.pdf).

## План эксперимента

В GUI задаются:

- `Total from`, `to`, `step` — суммарный поток;
- `H₂ : alkene` — фиксированное отношение;
- `Dwell / point, s` — одинаковая выдержка для стабилизации в каждой точке.

После `Validate plan` вкладка **Эксперимент** показывает таблицу точек с прокруткой. Кнопка `Open graph in a separate window` открывает масштабируемое окно графика уставок H₂/алкена, текущих измеренных расходов и активной экспериментальной точки. Уставки отображаются ступенями: каждая линия остаётся на своём значении в течение `Dwell / point, s`, затем переходит к следующей точке. Ось X показывает время эксперимента в секундах.

Вверху вкладки **Эксперимент** выбирается режим. В автоматическом режиме доступны план, таблица точек и график; запуск требует `Enable writing setpoints` и режим `Set flow` у обоих каналов плана. В ручном режиме для каждого подключённого MFC создаётся отдельная карточка в вертикальном списке с прокруткой: серийный номер, COM, газ в приборе, назначенная роль, режим MFC, текущий измеренный поток, прочитанная из прибора уставка и поле ввода нового потока. При отсутствии приборов карточек нет. Обновление измерений не меняет вводимый текст. В карточке MFC с режимом `Read flow` поле и кнопки недоступны. Можно управлять и каналом с ролью `Other`. В ручном режиме переключатель `Enable writing setpoints` скрыт: кнопки `Установить`, `Ноль` и Enter в поле отправляют команду сразу для MFC с режимом `Set flow`. Нулевая уставка не подменяет измеренное значение нулём: оба показания выводятся независимо. Пока выполняется автоматический план, переключение на ручной режим заблокировано; перед возвращением к автоматическому режиму вручную заданные ненулевые уставки нужно обнулить.

Например, значения `10`, `150`, `10`, `4`, `60` образуют 15 точек: 10, 20, …, 150. Для каждой точки рассчитываются `F_H2 = 0.8 × F_total` и `F_alkene = 0.2 × F_total`; каждая удерживается 60 секунд. До старта приложение проверит, что конечная точка укладывается в capacity обоих обнаруженных устройств и что единицы у них совпадают.

Нажмите `Validate plan`, затем включите `Enable writing setpoints` и выберите `Start experiment`. При обычном завершении и при нажатии `STOP` программа отправляет нулевые уставки H₂ и алкену. Если связь с прибором пропала, запись нулевой уставки не гарантирована — именно поэтому требуются аппаратные защиты.

## Конфигурация обнаружения

```json
"discovery": {
  "scan_interval_s": 2.0,
  "probe_timeout_s": 0.12,
  "ports": [],
  "include_non_usb": false,
  "slave_ids": [1, 2]
}
```

- Пустой `ports` сканирует USB-последовательные устройства раз в `scan_interval_s` секунд.
- Для встроенного или не-USB последовательного порта добавьте, например, `"ports": ["COM7"]` либо установите `include_non_usb: true`.
- `probe_timeout_s` не следует задавать ниже `0.4`; для двух MFC через USB-хаб рекомендуется `0.5` с.
- `slave_ids` сохранён для будущего режима RS485 Modbus; при прямом EL-FLOW Prestige RS232/ProPar он не используется.

EL-FLOW Prestige поддерживает Modbus на соответствующем RS485/опциональном интерфейсе, но его обычный USB–RS232 путь использует FLOW-BUS/ProPar. Именно этот интерфейс использует программа. [Руководство EL-FLOW Prestige](https://products.bronkhorst.com/media/dtrhzjhu/917084-manual-el-flow-prestige.pdf) и [документация ProPar](https://bronkhorst-propar.readthedocs.io/en/latest/).

## Проверка без оборудования

```powershell
.\.venv\bin\python.exe -m unittest -v
```

Тесты проверяют расчёт программы 10–150 с шагом 10 при отношении 4:1, границы последовательности и кодирование данных Modbus. Они не заменяют испытание с реальными MFC на безопасной инертной линии.
