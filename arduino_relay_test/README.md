# Проверка двух реле на Arduino Uno

Открой `arduino_relay_test.ino` в Arduino IDE, выбери **Arduino Uno** и COM-порт,
загрузи скетч. Открой монитор порта на **115200 бод**. Окончание строки любое:
CR/LF игнорируются. Перед первым тестом отключи 24 В клапанов.

## Подключение

- D4 Arduino → IN1 модуля.
- D5 Arduino → IN2 модуля.
- GND Arduino → GND модуля → минус внешнего источника 5 В.
- +5 В внешнего источника → VCC модуля; перемычка JD-VCC—VCC установлена.
- Arduino питается от USB; её 5V не соединять с внешним +5 В.

По умолчанию модуль включается низким уровнем (`RELAY_ACTIVE_LOW = true`).
Если твоя плата работает наоборот, поменяй эту константу на `false` и загрузи
заново. После загрузки оба реле должны быть выключены; проверь щелчок и
контакты. Скрипт не считывает физическое положение контактов.

## Команды

| Команда | Действие |
|---|---|
| `4` | Переключить реле на D4: OFF → ON → OFF |
| `5` | Переключить реле на D5 |
| `0` | Выключить оба реле |
| `?` | Вывести состояния и уровни выходов |

Команды обрабатываются по символам: `45` переключит оба реле. Неизвестный
символ выводит `ERROR` и не меняет состояния.

Пример ответа при команде `4`:

```text
[uptime_ms=8201] RELAY D4 command=ON pin=LOW
```

Каждые 5 с плата выводит `ALIVE` с временем работы и состояниями.

## Как увидеть перезапуск

При каждом запуске выводится:

```text
BOOT relay-test D4 D5; both relays commanded OFF
RESET_CAUSE MCUSR=0x0 UNKNOWN (bootloader may have cleared flags)
```

Повторный `BOOT` и обнуление `uptime_ms` означают новый запуск. Открытие
Serial Monitor обычно тоже сбрасывает Uno через USB/DTR: первый `BOOT`
при открытии ожидаем. Во время пропадания питания сообщение вывести
невозможно; оно появится после восстановления питания, если порт доступен.
Для просмотра стартового сообщения можно нажать RESET при открытом мониторе.

Скетч считывает флаги MCUSR: POWER_ON, EXTERNAL_RESET, BROWN_OUT и WATCHDOG,
если загрузчик их сохранил. У многих Uno загрузчик очищает этот регистр,
поэтому `UNKNOWN` — нормальный результат и не означает, что сброса не было.
Флаги не определяют точную причину электрической помехи.

Включён watchdog на 2 с: при зависании без обслуживания таймера он
перезапустит плату. При старте выходы переводятся в OFF. Пока работает
загрузчик, выходы ещё не управляются скетчем; для active-LOW платы можно
добавить подтяжки IN1 и IN2 к VCC модуля по 10 кОм, чтобы уменьшить риск
ложного включения при сбросе. Это не аппаратная блокировка.

Это отдельная тестовая прошивка: после её загрузки прежние команды
TRIGGER/NMR_DONE и TTL на D8/D2 не работают. Для возврата к ЯМР загрузи
`../arduino_nmr_ttl/arduino_nmr_ttl.ino`.
